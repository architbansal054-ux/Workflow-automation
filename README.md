# Workflow Automation

An automated AI workflow orchestration system built in Python to route and execute user requests, automate tasks, and manage data workflows efficiently.

## Project Structure

- `core/`: Core engine orchestration logic (`engine.py`) and utility tools (`tools.py`).
- `workflows/`: Workflow execution logic and handler definitions (`handlers.py`).
- `main.py`: Main application entry point.
- `req.txt`: Project dependencies and package requirements.
